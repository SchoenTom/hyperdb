# Data Dictionary

> One row per column: name, type, unit, source, constraints. The authoritative schema is
> `src/core/db.py`; this document is the human-readable mirror and is regenerated by
> `cli.py docs --dictionary` after the schema is finalized. Tables below list the v2 design;
> row counts and value ranges marked `‹build›` come from the actual build.

## dim_company / dim_entity / dim_listing (identity — see ENTITY_RESOLUTION.md)
| Column | Type | Notes |
|---|---|---|
| company_id | TEXT | PERMCO-analogue (issuer) |
| entity_id | TEXT | PERMNO-analogue (security over its life) |
| listing_id | TEXT | one (exchange,ticker,currency) interval |
| primary_isin | TEXT | anchor identifier (nullable pre-2000/EM) |
| first_seen / last_seen | DATE | listing/entity interval bounds |
| match_method / confidence | TEXT / REAL | resolution provenance |
| delist_date / delist_reason | DATE / TEXT | for survivorship + Shumway |

## bronze_price_daily
| Column | Type | Notes |
|---|---|---|
| asset_id, date | TEXT, DATE | PK |
| open/high/low/close | REAL | **raw (unadjusted)** |
| adjusted_close | REAL | vendor-adjusted (cross-check only) |
| volume | BIGINT | |
| vintage_id | TEXT | provenance (immutable Bronze) |

## silver_price_daily
| Column | Type | Notes |
|---|---|---|
| return_pit | REAL | point-in-time total return (primary) |
| return_vendor | REAL | from adjusted_close (cross-check) |
| screen_flags | INT | bitmask: low_price/reversal/extreme/stale/sentinel |

## gold_monthly_panel
| Column | Type | Notes |
|---|---|---|
| asset_id/entity_id, month | TEXT, DATE | PK on entity-month |
| return_local/usd/eur | REAL | multi-currency monthly |
| mktcap_beg | REAL | **t-1** weight (no look-ahead) |
| beta_local/global, sigma_i, rho_im | REAL | F&P-2014 |
| delisting_return, delisting_flag | REAL/INT | Shumway |
| trading_days, n_daily | INT | coverage |

## meta_manifest / meta_vintage
Per-response provenance: `endpoint, params_json, response_sha256, n_rows, fetched_at,
vintage_id`. Underpins the reproducibility guarantee (T22).
